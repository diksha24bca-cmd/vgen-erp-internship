# MARG ERP Overview

## Introduction

MARG ERP is an enterprise resource planning software used to manage different business activities in one system.

It provides various modules for managing business operations such as purchase, sales, inventory, accounts, GST and reports.

## Main Functions

The MARG ERP software provides access to:

- Masters
- Transactions
- Accounts
- Purchase
- Sales
- Inventory
- GST
- e-Way
- Reports
- Stock Management
- Ledger Management

## Dashboard

The main dashboard provides shortcuts to commonly used functions such as:

- Sale
- Purchase Bill
- Receipt
- Payment
- Ledger A/c
- Outstanding
- Stock Status
- Stock & Sales Analysis
- Re-Order
- Sales Book

## Purpose

This section provides an overview of the MARG ERP software and its main functions used for business management.
